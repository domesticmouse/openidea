# ide-terminal

## Overview
Crate root for PTY terminal session management, shell integration scripts, and streaming UTF-8 decoding.

## Subdirectories & Boundaries
- [src](./src/README.md) - Cross-platform PTY session manager (`portable-pty`) with shell auto-detection, automatic shell integration injection (`zsh`/`bash`/`fish`), incremental UTF-8 output decoding, and foreground busy detection.
