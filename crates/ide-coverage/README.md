# ide-coverage

## Overview
Crate root for `ide-coverage`, providing multi-language test coverage instrumentation, report parsing, and CI report importing.

## Subdirectories & Boundaries
- [src](./src/README.md) - Test coverage command-line instrumentation (`prepare`), report collection (`collect`), and CI tracefile import (`import`) for LCOV, JaCoCo XML, and Go cover profiles.
