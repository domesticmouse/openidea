# ide-dap

## Overview
Crate root for `ide-dap`, providing the Debug Adapter Protocol client, adapter process management, and multi-language debugging support.

## Subdirectories & Boundaries
- [src](./src/README.md) - Debug Adapter Protocol (DAP) client, adapter resolution and launching, breakpoint store, process attach discovery, and JVM/Kotlin JDWP relays.
