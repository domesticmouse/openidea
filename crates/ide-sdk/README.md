# ide-sdk

## Overview
Crate root for SDK/toolchain discovery, external library resolution, and workspace SDK configuration overrides.

## Subdirectories & Boundaries
- [src](./src/README.md) - Discovers installed JDKs, Python interpreters/virtualenvs, Go/Rust/Node/Ruby/PHP/Elixir/Haskell/Julia/OCaml/.NET toolchains, external library roots, and applies user SDK overrides to language servers, build tools, terminals, and run/debug configurations.
