# ide-run

## Overview
Crate root grouping run configuration detection, persistence, process execution, and CLI examples.

## Subdirectories & Boundaries
- [examples](./examples/README.md) - Command-line example binary that detects and prints run configurations for a target project directory.
- [src](./src/README.md) - Core implementation of run configuration auto-detection, `.openidea/run.toml` persistence, PTY/pipe process lifecycle management, Java command-line shortening, JUnit XML parsing, and Tomcat `CATALINA_BASE` staging.
