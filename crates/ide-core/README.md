# ide-core

## Overview
Crate root for `ide-core`, defining the shared IPC vocabulary, settings schemas, event bus, and process utilities for all OpenIDEA crates.

## Subdirectories & Boundaries
- [src](./src/README.md) - Foundational types, settings schemas, IPC path/text primitives, child-process environment preparation, and backend-to-UI event bus shared by all OpenIDEA crates.
