# ide-db

## Overview
Crate root for `ide-db`, providing database connections, SSH tunneling, schema introspection, SQL splitting, and table data editing across SQLite, PostgreSQL, MySQL, and SQL Server.

## Subdirectories & Boundaries
- [src](./src/README.md) - Database tool window backend supporting SQLite, PostgreSQL, MySQL/MariaDB, and SQL Server: data sources, SSH-tunneled connection pools, catalog introspection, DDL generation, query execution, execution plans, and table editing.
