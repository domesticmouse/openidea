# ide-tools

## Overview
Crate root for managed external developer tools, language server/debugger installers, JDK downloads, and remote server binary fetching.

## Subdirectories & Boundaries
- [src](./src/README.md) - Managed external tool registry, installer, and updater for language servers, DAP debug adapters, Prettier, Lombok, Eclipse Temurin JDK/JRE builds, and `openidea-server` remote binaries.
