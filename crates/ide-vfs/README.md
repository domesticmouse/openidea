# ide-vfs

## Overview
Crate root for `ide-vfs`, providing virtual filesystem operations, text encoding detection/conversion, ZIP/JAR archive reading, directory comparison, and filesystem watching.

## Subdirectories & Boundaries
- [src](./src/README.md) - Provides virtual filesystem operations, character encoding detection and conversion, `.properties` Unicode escape handling, atomic file writes, read-only ZIP/JAR archive browsing, directory tree comparison, and debounced filesystem event watching.
