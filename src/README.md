# src

## Overview
React 19 + TypeScript + CodeMirror 6 frontend root containing the application entry point (main.tsx), auto-generated Tauri IPC bindings (bindings.ts), and the editor, features, platform, ui, and workbench layers.

## Interface
- [main.tsx] Application bootstrap entry point mounting either Workbench (main/project windows) or SettingsWindow (child settings-<parent> windows), installing the keyboard dispatcher after feature capture-phase listeners, hiding the splash screen, and prefetching lazy UI chunks.
- [bindings.ts:commands] Auto-generated tauri-specta type-safe IPC command bindings and shared Rust/TypeScript data transfer types (Settings, IdeEvent, ProjectInfo, WorkingTreeChange, etc.).
- [editor](./editor/README.md) - Editor subsystem root defining the public CodeMirror 6 extension contract (api.ts) and housing core, lsp, navigation, refactor, and structure packages.
- [features](./features/README.md) - Self-contained IDE feature modules (editor integrations, tool windows, settings pages, dialogs, and background services) orchestrated by activateFeatures and activateSettingsWindowFeatures.
- [platform](./platform/README.md) - Frontend platform layer providing typed Tauri/remote IPC, action registration, context-key when evaluation, keyboard dispatch, project/settings stores, i18n, and path/font utilities.
- [ui](./ui/README.md) - Reusable React design-system primitives, icons, keyboard-navigable Tree/List/Tabs/Menu/Dialog/Popup components, split panels, pointer drag-and-drop, and fuzzy matching.
- [workbench](./workbench/README.md) - The 'Islands' IDE workbench shell (TitleBar, ToolWindows, EditorArea, StatusBar, OverlayHost, Notifications) and central extension registries (contributions.ts).

## Invariants
- [main.tsx] Calls activateFeatures() strictly before installKeyboardDispatcher() so capture-phase feature key handlers (such as the terminal shortcut interceptor) run before the global shortcut dispatcher.
- [bindings.ts] Generated by cargo test -p openidea export_bindings; never hand-edited.

## Side Effects
- [main.tsx] Mounts the React root on #root, exposes window.__TAURI__ in dev Tauri builds for MCP evaluation, registers dev sample data in browser/perf mode, hides the native splash screen, and prefetches lazy components.
