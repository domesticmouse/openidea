# project-tree

## Overview
Virtualized, lazily loaded Project tool window (project) supporting multiple view panes (Project, Project Files, Open Files, All Changed Files, Scratches and Consoles), file/folder creation, safe delete, reference-updating move/rename refactorings with preview and undo, OS clipboard/drag-and-drop integration, and directory role marking.

## Invariants
- [operations.ts:mutable] [store.ts:isReadOnlyPath] Root nodes, placeholder nodes, group nodes (\0group:), and library nodes (\0lib: or readOnly roots) cannot be renamed, moved, or deleted, nor receive new/pasted/dropped files.
- [store.ts:loadDir] [store.ts:loadOutline] Concurrent requests for the same path share one in-flight promise and discard results if generation advances.
- [fileRefactor.ts:withEditorsFollowing] Before running or undoing a file refactoring, all dirty editors are saved (editor.saveAll()), and open tabs under moved paths are reopened at their movedPath locations.
