# agents

## Overview
Coding agents integration (Claude Code, Codex, Gemini CLI, and ACP Registry agents) providing the Agents tool window, session and new-task editor tabs, prompt composer with @ file and / command completion, and the ACP Registry settings page.

## Invariants
- [store.ts:connect] — Increments generation on every connect/disconnect and discards stale event channel notifications or RPC responses when gen !== generation; skips commands.agentProviders() when project.trusted === false.
- [model.ts:upsertEntry] — Returns null when index > entries.length so out-of-order entry indices trigger a full loadEntries reload instead of creating sparse arrays.
- [composerModel.ts:completionAt] — Triggers slash-command completion (/) only when typed as the first token of the prompt (before.slice(0, from).trim() === '').
- [composerModel.ts:MAX_IMAGE_BYTES] — Rejects attached or pasted images larger than 5 MB (5 * 1024 * 1024 bytes).
- [HomeEditor.tsx:HomeEditor] — Forces task isolation to 'local' when the selected target project is not a Git repository (!isGit).
- [AgentRegistryPage.tsx:ExternalLink] — Renders external registry links only when href matches /^https?:\/\//i.

## Side Effects
- [store.ts:connect], [store.ts:startTask], [store.ts:sendMessage] — Subscribes to backend agent events via Tauri Channel<AgentEvent> (commands.agentSubscribe) and invokes agentCreate, agentPrompt, agentFork, agentRollback, agentCancel, agentRespond, agentArchive, agentUnarchive, agentDelete, agentEntries, agentChanges, agentProviders, and agentCommands.
- [store.ts:save], [SessionEditor.tsx:useChangesOpen] — Persists draft settings (openidea.agents.draft.v2), prompt history (openidea.agents.history.v1), session location (openidea.agents.sessionLocation.v1), and changes pane visibility (openidea.agents.changesOpen.v1) in localStorage.
- [registry.ts:tauriRegistry] — Lists, installs (with streaming Channel<InstallEvent>), removes, and cancels ACP Registry agents via commands.agentRegistryList, commands.agentRegistryInstall, commands.agentRegistryRemove, and commands.cancelRequest.
- [Composer.tsx:Composer] — Listens to Tauri webview drag-drop events (getCurrentWebview().onDragDropEvent), reads dropped images via invokeLocal('fs_read_image'), and queries project files via commands.findFiles and commands.pathCompletions.
- [Markdown.tsx:markdownHtml] — Sanitizes rendered Markdown via DOMPurify.sanitize and probes referenced file paths via commands.fsProbe.
