# database

## Overview
Database tool window, query console editor extension, result-set grid and chart views, table data editor, data extractors/importers, and schema/object management dialogs for PostgreSQL, MySQL/MariaDB, SQLite, SQL Server, and wire-compatible databases.

## Invariants
- [TableEditor.tsx:TableEditor] — Tables without a primary key (pk.length === 0) or belonging to a readOnly data source are strictly read-only.
- [model.ts:connectRemedy] — Never offers host-key trust when an SSH host key has changed (/^SSH host key .* has changed/).
- [store.ts:setManualCommit] — Prompts the user to commit or roll back when switching a data source from manual commit to auto-commit while pendingTx has uncommitted changes.
- [store.ts:executeConsole], [store.ts:log] — Caps result tabs at MAX_TABS (12) and console output lines at MAX_OUTPUT (2000).

## Side Effects
- [store.ts:loadSources], [store.ts:saveSource], [store.ts:executeConsole] — Communicates with backend database commands (dbSources, dbSaveSources, dbSetPassword, dbSetSshSecret, dbTrustSshHost, dbConnect, dbDisconnect, dbDatabases, dbSchemas, dbTables, dbSchemaObjects, dbTableDetails, dbCompletion, dbStatements, dbExecute, dbExplain, dbFinishTransaction, dbSetManualCommit, dbTablePage, dbApplyEdits, dbDdl, dbObjectDdl, dbExportFile, dbHistory, dbRemoveHistory).
- [store.ts:bindConsole], [index.ts:activate] — Persists console-to-datasource bindings in localStorage['openidea.database.consoles'], applies data source color tints to console files via setFileDecorations('database', ...), and runs [store.ts:watchIdleConnections] to auto-disconnect idle targets.
- [sqlSupport.ts:sqlSupport] — Publishes unresolved SQL symbol diagnostics under producer 'sql-inspections' via setFileDiagnostics.
