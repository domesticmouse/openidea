# data

## Overview
Data, caching, and mutation layer for GitHub repository connections, paginated pull request lists, per-PR slice stores, local Git/worktree operations, unread state, and search history.

## Invariants
- [local.ts:withBusy] — Serializes long-running `gh`/Git operations via `useGhBusy`; concurrent invocations notify `"Another GitHub operation is still running"` and return `null`.
- [pullRequest.ts:reloadPullRequestData] — Protects per-PR slice loads with monotonic `seq` and repository `epoch` counters, and re-polls `UNKNOWN` mergeability up to `MERGEABILITY_RECHECKS` (10) times at 3000ms intervals.
- [operations.ts:setViewed] — Updates `viewedState` optimistically and reloads `viewedState` from GitHub if any file mutation fails.

## Side Effects
- [repository.ts:refreshConnection], [local.ts:checkoutPullRequest], [local.ts:prepareDiff], [local.ts:openInWorktree] — Calls backend IPC (`ghAvailability`, `vcsRemotes`, `ghPrCheckout`, `ghPrPrepareDiff`, `vcsAddWorktree`, `cancelRequest`, `fsReadText`), opens external URLs, writes to the clipboard, and persists repository choice, last-seen timestamps, and search history in `localStorage`.
