# api

## Overview
Typed GitHub GraphQL and REST API client executing authenticated requests through the backend `gh api` IPC command with automatic transitive GraphQL fragment assembly.

## Invariants
- [client.ts:currentRepository] — Throws `"Not connected to a GitHub repository"` if a repository-scoped request is called when `current` is `null`.
- [client.ts:repoPath], [client.ts:repoVariables] — Explicitly inject `owner` and `name` from `currentRepository()` rather than relying on `gh` CLI's `{owner}/{repo}` placeholder resolution so multi-remote workspaces target the selected repository.
- [document.ts:withFragments] — Deduplicates transitive fragment spreads and omits fragments already declared inline in the query document.

## Side Effects
- [client.ts:graphql], [client.ts:rest] — Spawns `gh api` requests via backend IPC `commands.ghApi`.
- [client.ts:setCurrentRepository] — Updates module-scoped active repository coordinates.
