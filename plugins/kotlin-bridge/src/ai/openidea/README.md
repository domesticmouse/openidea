# openidea

## Overview
Intermediate Java package namespace (`ai.openidea`) for the JDT LS side of the Kotlin binary bridge.

## Subdirectories & Boundaries
- [kotlin](./kotlin/README.md) - JDT LS delegate command (`KotlinLibraries`) managing `ai.openidea.kotlin=true` binary classfolders on Eclipse JDT project classpaths and restoring them after Maven reimports.
