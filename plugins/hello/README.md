# hello

## Overview
Package root for the sample `hello` WebAssembly plugin (`openidea-plugin-hello`), grouping its `plugin.toml` manifest, standalone `Cargo.toml`, and Rust guest source directory.

## Subdirectories & Boundaries
- [src](./src/README.md) - Rust WebAssembly guest implementation for the sample `hello` plugin (`openidea:plugin/plugin@0.1.0`), providing the `insert-date` and `word-count` IDE commands.
