# openidea

## Overview
Intermediate Java package namespace (`ai.openidea`) for the Java semantic usages JDT LS extension.

## Subdirectories & Boundaries
- [usages](./usages/README.md) - JDT LS OSGi delegate command (`openidea.java.usages`) and AST-based structural read/write usage classifier for Java fields, getters, setters, builders, and Lombok `@Accessors`.
